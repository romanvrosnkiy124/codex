# Руслан Рагимов

Сайт на Next.js с App Router и TypeScript. Менеджер пакетов — npm.
Главная страница содержит практики, биографию и опыт, судебную практику, отзывы, публикации и контакты.

## Требования

Node.js 20.9 или новее и npm. Рекомендуется актуальная LTS-версия Node.js.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Production-сборка

```bash
npm run build
npm start
```

Перед публичным запуском задайте `NEXT_PUBLIC_SITE_URL` — подтверждённый абсолютный HTTPS-адрес сайта, например в `.env.local` или настройках production-окружения. Значение используется при сборке для canonical, Open Graph, sitemap и robots; после изменения нужна новая сборка.

Пока домен не задан, используется резервный placeholder `https://example.com`, а индексация отключена. В Vercel Preview / Development индексация также отключена. Для production с подтверждённым HTTPS-доменом она разрешается. На другом хостинге для непубличного preview задайте `VERCEL_ENV=preview` при сборке.

Скрипт lint в проекте не настроен. Сборка проверяет TypeScript; отдельно можно выполнить `npx tsc --noEmit`.

## Структура

- `app/layout.tsx` — корневой layout и метаданные.
- `app/page.tsx` — главная страница.
- `app/privacy/page.tsx` — политика конфиденциальности.
- `app/not-found.tsx` — страница 404.
- `app/sitemap.ts`, `app/robots.ts` — служебные маршруты SEO.
- `app/icon.svg` — локальная монограмма RR для значка сайта.
- `lib/site-config.ts` — имя, домен, контакты и социальные метаданные.
- `tsconfig.json` — конфигурация TypeScript.
- `next-env.d.ts` — типы Next.js (генерируется Next.js).
- `package-lock.json` — зафиксированные версии зависимостей.

## Интерфейс

- `components/` — блоки страницы, мобильное меню и анимации.
- `lib/gsap.ts` — GSAP и регистрация ScrollTrigger.
- `app/globals.css` — адаптивная вёрстка, палитра и локальные шрифты.
- `public/fonts/` — Cormorant Garamond и Manrope (WOFF2), с лицензиями.
- `next.config.ts` — разрешённое качество оптимизации изображений.

Анимации используют GSAP и ScrollTrigger, плавный скролл — Lenis.
При `prefers-reduced-motion: reduce` интро, параллакс и плавный скролл отключаются.
Контент доступен и без JavaScript.

Hero и социальные метаданные используют утверждённый локальный портрет `public/images/ruslan/ruslan-hero-reference.webp`. Изображения выводятся через Next/Image: hero предзагружается, остальные загружаются отложенно. Оригинальные изображения сохранены.

Все шесть пунктов меню ведут к секциям главной страницы с учётом высоты шапки. Мобильное меню блокирует прокрутку фона, закрывается по ссылке и Escape и удерживает клавиатурный фокус. Кнопки «Обсудить ситуацию» ведут на https://t.me/ragimovlaw в новой вкладке. В финальном блоке контактов также доступен WhatsApp: https://wa.me/79509975756.

## Перед публичным запуском

- Задать подтверждённый production-домен в `NEXT_PUBLIC_SITE_URL` и пересобрать сайт.
- Финально проверить юридический текст `/privacy`, включая фактическую обработку обращений и условия хостинга.
- Заменить временные ссылки на главную SUDNOTICE прямыми ссылками на две подтверждённые статьи в `lib/media-content.ts`.
- Подтвердить материалы дел, отзывы и численные показатели: данные кейсов/отзывов сохраняют внутренний статус примеров и не становятся проверенными от публикации сайта.
